Sequence Diagram — Creazione di un Paziente da parte del Medico

sequenceDiagram autonumber actor Medico participant FE as Frontend participant DC as DoctorController participant DS as DoctorService participant DB as Database participant NM as NodeMailer Medico->>FE: Compila form e clicca aggiungi (email, cf, phone, dati clinici) FE->>DC: POST /doctor/invite (CreateInviteDto) DC->>DS: createInvite(user.id, inviteDto) Note over DS: getDoctorOrThrow(userId) DS->>DB: doctorRepository.findOne({ dove user.id: userId }) DB-->>DS: Doctor Note over DS: findUser(email, phone, cf) DS->>DB: userRepository.createQueryBuilder(...) DB-->>DS: User | null alt Paziente/User già esiste DS-->>DC: throw BadRequestException("Tale paziente già esiste") DC-->>FE: HTTP 400 Bad Request FE-->>Medico: Mostra errore else Paziente non esiste Note over DS: createPatient(createInviteDto, doctor) DS->>DB: patientRepository.create(...) + save(patient) DB-->>DS: Patient salvato (senza utente per ora) DS->>DS: generateRandomPassword() DS->>DS: hashPassword(password) con bcrypt Note over DS: createUserPatient(info, hashedPassword) DS->>DS: findUser(email, phone, cf) DS->>DB: userRepository.createQueryBuilder(...) DB-->>DS: User | null alt User esiste in questo controllo intermedio DS-->>DC: throw ConflictException("User already exist") DC-->>FE: HTTP 409 Conflict FE-->>Medico: Errore conflitto else Nessun conflitto, procede alla creazione utente DS->>DB: userRepository.create(dati anagrafici, role: PATIENT, mustChangePassword: true) DS->>DB: userRepository.save(user) DB-->>DS: User salvato Note over DS: assignPatientToUser(doctor.userId, patient.id, newUser) DS->>DB: patientRepository.findOne(id: patient.id, doctorId: doctor.userId) DB-->>DS: Patient trovato DS->>DB: patient.user = newUser DS->>DB: patientRepository.save(patient) DB-->>DS: Patient aggiornato (Utente collegato al Paziente) Note over DS: sendPasswordEmail(email, password) DS->>NM: transporter.sendMail(mailOptions) Note over NM: Invia credenziali via Email (testo & HTML) al paziente NM-->>DS: Conferma invio (console.log) DS-->>DC: { patientId: patient.id } DC-->>FE: HTTP 201 Created { patientId } FE-->>Medico: Redirect o notifica di successo end end
